Install

Download Sigil.zip from the latest GitHub release. Unzip it and replace /Applications/Sigil.app.

The first time you open it, macOS may say it cannot verify Sigil. Open System Settings → Privacy & Security and choose Open Anyway, or run xattr -dr com.apple.quarantine /Applications/Sigil.app in Terminal.

Needs macOS 14 or later, and the grok CLI at ~/.grok/bin/grok. The universal zip includes Apple silicon and Intel executables. You can set another path in Settings.

Sidebar, search, and tabs

The sidebar lists every conversation on this Mac. Home is the project list. Open a folder to see its chats.

Search by title, folder, or path. Click a chat to reopen it. If it is already open, Sigil moves to that tab.

Tabs keep several sessions at once, each in its own folder. The sessions you had open come back on the next launch.

Keyboard

ShortcutAction
⌘TNew session
⌘⇧NNew session (same as ⌘T)
⌘WClose tab
⌘⇧FFind conversations
⌘BHide or show the thread list
⌘,Settings

In the thread list, arrow keys move the selection, Return opens it, and F2 renames it.

Pair a phone

Remote access is off by default. Open Settings, then Remote. The companion is https://remote.sigilapp.dev.

  1. Confirm that address and select Connect Phone.
  2. Scan the QR on the phone.
  3. Add to Home Screen from Safari as a shortcut. If iPhone offers Open as Web App, turn it off.

Sigil must stay open to control sessions. Disconnect revokes the pairing. If you paired before the companion moved to https://remote.sigilapp.dev, scan again.

To host your own companion, deploy the Sidereal directory over HTTPS and enter that origin in Settings → Remote. A phone cannot use localhost.

Limits

The phone can select open sessions, read recent terminal output, send text, attach files, and stop a running turn. It does not list closed conversations.

Pair one phone at a time. Do not share pairing QR screenshots.
