A native macOS shell for the Grok Build CLI that runs the real grok terminal UI and lists every conversation you have ever had, searchable, one click from resuming.

Download Sigil.zip

Unzip the file and replace /Applications/Sigil.app. Needs macOS 14 or later on Apple silicon. The zip is the GitHub Actions Mac build, not a universal binary.

Pair a phone

  1. Open Settings, then Remote.
  2. Select Connect Phone. The companion is https://remote.sigilapp.dev.
  3. Scan the QR on the phone.
  4. Add to Home Screen from Safari as a shortcut, not a web app. A phone cannot use localhost.
