# REA-1202: refresh when the web page returns

## Current-main reproduction

Before production edits, one new regression ran the existing fake-DOM browser harness against unchanged main. After authorization, hiding and showing the page sent **no immediate state request** and left the pill **Connected**, with `data-connected=true`. The test failed exactly against one immediate state request and a non-green **Refreshing…** state. Only the regression test had changed; production `app.mjs` was identical to main. This is generated fixture evidence, not a device reproduction.

```sh
node --test --test-reporter=tap --test-name-pattern='^REA-1202 short return' Sidereal/test/app.test.mjs
```

## Resulting behavior

- A short return requests fresh state through the existing serialized queue without a one-second poll delay. A send already in progress finishes its files/paste/Enter transaction first; refresh follows immediately afterward.
- More than 30 seconds hidden replaces the connection immediately. A backwards/invalid clock measurement also chooses conservative recovery. The threshold is a heuristic, not proof the socket died.
- Visibility and BFCache page events share one hidden interval and one outstanding refresh. Initial background loads are tracked as well. A later hide or selection supersedes an old read.
- Until a current validated state arrives, the connection pill and live status say **Refreshing…**. New remote actions are disabled; the draft remains editable. Old polls and stale connection/page/selection continuations cannot declare freshness. A changed authoritative selected tab or an empty snapshot remain supported.
- Fresh authorization also requires a returned state; `ok: true` alone cannot turn old output green. Missing state closes into the existing reconnect backoff instead of leaving an unbounded connecting state.
- Application commands are not replayed. Existing encryption, challenge/nonce checks, wire fields, request serialization, unknown-start persistence and the ten-second command deadline are retained. The refresh token stays local to the view.
