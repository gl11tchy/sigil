# REA-1212: bounded APNs session recovery

Ticket: [REA-1212](https://linear.app/reasonable-glyph/issue/REA-1212/reopen-a-stale-apns-connection-so-the-first-alert-after-a-quiet-spell).
Base: `6010b13293f722938c8b7d08361a77e5db4cfd76`.

Unchanged-code generated loopback HTTP/2 reproduction failed one focused test
after two 10s waits: both sends returned status0 and reused one connection whose
server accepted requests without answering. Expected recovery was status200 for
both sends and two connections. No Apple call or production outage was observed.

One send snapshots body/headers/collapse/timestamp/expiry before transport. No
response permits one fresh attempt; any response, including informational/error
status, forbids retry. Absolute attempt10s/total20s monotonic budgets are clipped
to original expiry. Expired work cannot start or retry; wall-clock rollback does
not enlarge the initially clipped budget. Idle10-minute close applies only when
no request is pending. Retired connections and old callbacks retain identity;
concurrent failures share a replacement. Shutdown cannot resurrect connections.
HTTP/2 retry stays inside one logical send, so room rate charges remain one.

All27 focused Node APNs/relay-push checks passed: original recovery, simultaneous
failures/stale callbacks, accepted/refused GOAWAY, any response status, idle versus
active work, admission/retry expiry, total deadline despite body traffic, shutdown,
mutable-caller snapshots and possible duplicate attempts with fixed activity order.
A real relay plus local HTTP/2 server captured61 wire attempts for60 logical
acceptances; the next logical send was rate-limited. Generated keys, loopback hosts,
owned fixture cleanup only. Constructor timeouts can be shortened for tests but
cannot exceed production limits. Legacy zero-expiration behavior stays unchanged.

Existing iPhone receipt logic is exercised in a new CI-only test opening the same
sealed event twice and consuming only one actionable receipt. The notification
extension may still show a passive local fallback; this does not prove complete
visual suppression. Capture of original timestamps/order is not physical APNs
ordering proof. No exactly-once or device-delivery guarantee is claimed.

[Node22 HTTP/2 documentation](https://nodejs.org/docs/latest-v22.x/api/http2.html)
was downloaded from the official site: GOAWAY retires transport, stream/session
timeouts report inactivity, and graceful close allows existing streams to finish.
Absolute owned timers bound waiting independently of network activity.

Final exact-head CI/check counts are recorded in the PR after observation. No
local AppTests/build, denied retries, process enumeration, personal data, actual
Apple/provider calls, relay deployment, security/access/credential change or app
installation. Protected PR162 and all twelve prior manual-review records remain
preserved. Parent personal final code/CI review before merge; no next ticket.
