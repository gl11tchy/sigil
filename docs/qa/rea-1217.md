## Change

noteTab returns immediately while disabled. Both immediate/suppressed and delayed
evaluation check eligibility before prompt/title reads: an alert token, or a
non-ending activity for this tab. Unsubscribed tabs do no activity-only work.
Planner membership uses direct dictionary knows(tabID:) lookup; the existing
knownTabs inspection API remains for compatibility.

Alert and activity snapshots have separate planners. Newly eligible/replaced
consumers get fresh baselines. An activity registration forgets only that tab's
activity baseline; a changed alert token/environment resets only alert baselines.
Refreshing an unchanged token preserves its baseline. No registration globally
resets other consumers. Disabling clears cached baselines because off-state
changes are deliberately unobserved; ordinary enabled relay reconnects keep them.

Pending evaluations have ownership UUIDs. Consumer removal cancels only tasks
without another eligible consumer, and callbacks cannot clear a replacement
task. Ending activities retain their existing queued end but stop evaluating.
Selected watch streaming stays on noteChange and is independent of this gate.
