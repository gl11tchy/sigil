## Bounded behavior and fixtures

Automatic binding returns an opaque receipt containing the exact device/inode,
fresh native envelope and child process generation. It preserves the existing
single writable rollout, supported metadata, exact cwd and stable process-tree
proof. Late journal attachment checks that receipt before and after reads, plus
the fixed metadata prefix and prior read boundary. Loss or ambiguity ends tracking.
Explicit user links retain tail-only behavior and do not claim automatic ownership.

Only a newly created, automatically owned rollout catches up from zero, bounded
to 256 KiB per poll and the attachment's initial size. Event times must follow
the kernel child birth time. Catch-up publishes the final state quietly; the first
active turn can complete live afterward, while an already finished turn does not
replay an unread dot, settle callback or phone alert. Partial records finish when
later bytes arrive. Later submissions after interruption tail the current file.
Restart retains the learned transcript. Mid-turn Return keeps the original watcher.

Generated Kit fixtures cover active/complete first turns, pre-launch rejection,
partial records, multi-poll catch-up, appended headers, replacement, truncation,
same-inode rewrite, lost ownership, a changing before/after lease and file mutation
at the final lease before publication. CI-only App
fixtures cover delayed identity, background completion, queued turns, quiet
completed attachment, lifecycle phone snapshots, ambiguous ownership, file changes,
interruption, retained restart and delayed results after closing or replacing a tab.
Capability loss publishes to the phone stream even if state remains Unknown.
The existing loopback relay captures actual RemoteControl frames locally instead
of contacting Apple. Focused away-phone cases cover Unknown-to-Working and
Working-to-Idle catch-up: the registered activity receives state, historical
alerts stay suppressed, a later ordinary look cannot replay the transition, and
a subsequent live turn produces exactly one decryptable finished alert.
All new kernel observations are synthetic; fake CLI homes and journals are isolated.
Existing exact binding and watcher-ownership negative tests remain intact.
