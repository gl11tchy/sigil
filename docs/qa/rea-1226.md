# REA-1226 — smoke-launch the release bundle

Base: `b4d32fdd48a4e07bd98e7462b8c9faed0d8ed09c`.

The release build previously went directly to `ditto` and publication. The new
workflow step runs the same helper used for the temporary debug verification
bundle on `dist/Sigil.app`, with the build/zip event condition unchanged. A failed
launch fails the step; subsequent zip/publication steps retain their ordinary
success dependency. Manual dispatch can build/smoke/zip but cannot publish.

The helper launches the supplied executable directly, with an isolated HOME,
CFFIXED_USER_HOME, GROK_HOME, TMPDIR, XDG cache/config and working directory, plus
the existing smoke environment flag and argument. It samples liveness after
three seconds, stops/reaps its own child and removes only its temporary home.
It logs the executable SHA256 and rejects a change during launch. The bundle
stays in place for the existing zip step; it is not installed or rebuilt between
smoke and packaging. This digest is an executable receipt, not a complete
source/signing provenance system or proof of UI correctness.

Observed local evidence (generated shell executables only):

- Before production changes, `node --test Sidereal/test/ci-artifacts.test.mjs`
  returned 3 existing passes and 3 new failures: absent release smoke step and
  missing helper. No real app was launched.
- Final focused run: 8 passed, 0 failed/skipped. It checks workflow order/event
  conditions, debug caller reuse, relative bundle paths containing spaces,
  isolated environment/working directory, child termination, state cleanup,
  unchanged executable bytes, invalid arguments and executable mutation.
- A generated executable exiting successfully before three seconds fails the
  helper and prevents subsequent synthetic zip/publication markers. No GitHub
  release was created by this fixture.
- Two intermediate fixture runs failed only on doubled separators in the
  temporary path. The final assertions compare normalized paths on both sides;
  environment equality, isolation, cleanup and process assertions remain.
- `bash -n` for both changed scripts, shellcheck for both, and `git diff --check`
  passed. The final native/integrated CI result is pending at this commit.

Review and runtime limits:
