## Scope and contracts

- Union pins, archives, custom names and tab colors with existing ownership IDs.
  Preserve exact provider-qualified IDs, including unknown and unreadable history.
- Store membership in independent immutable addition records; retain the old JSON list for compatibility.
  Controlled overlapping writes must preserve both copies' distinct identities.
  One record holds the new IDs in each batch, preserving the existing bulk archive
  write-count assertion without changing it.
- Confirm the ownership write and readback before marking migration complete.
  Test failure before/after a write, an acknowledgement without a write, and a
  failed completion-marker write. Retry must preserve prior IDs.
- Reconcile later ownership arrivals even after migration completion; a failed
  future action can recover from its saved metadata on relaunch or shared reload.
- Test pin/name/archive/color individually, archive count/list agreement,
  tab-only rename/color, no-op changes and pending Codex identity.
- Merely opening an outside chat uses a generated fake CLI and retains exclusion
  after closure. A generated note alone does not establish ownership.
- No notes listing/migration, provider binding, cwd/time matching, transcript
  mutation, remote protocol or deletion policy changes.
