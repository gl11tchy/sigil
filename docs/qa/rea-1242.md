## Change and focused coverage

- File → Reopen Closed Tab (Shift-Command-T) uses the normal startup gate and a
  model availability predicate. The in-memory list holds at most10 unique
  successful user closes, retaining native provider ID, workspace, tab position,
  model and effort. Explicit empty CLI options remain empty after defaults change.
- Reuse the existing native identity/capability and restoration-spec rules. A
  new process requires a fresh history scan, validated matching provider/ID/cwd,
  available provider/folder and a usable history source. Missing folder/provider
  retains the entry for deliberate retry. Unknown history is retained; confirmed
  missing history is skipped only with complete authoritative coverage.
- An already-open exact chat is selected without another process. A per-record
  token, one in-flight action and selection/new-session checks protect the scan
  boundary. A newer close, manual open, new-session choice or quit cannot consume
  the wrong entry or start a duplicate.
- A competing forced scan can supersede the refresh this action awaited. A new
  applied scan and completed loading are required before visible rows can be used
  as evidence; otherwise the entry remains available for retry. The independently
  held-scan regression releases the superseded scan while its newer replacement
  remains pending.
- CI695 exercised all1,388 Swift tests and passed the superseding-scan case;
  the malformed-summary case failed two assertions because a retained Grok display
  row kept its prior validation flag. The correction consults a read-only projection
  of existing Grok coverage/target-summary uncertainty. Scanner/cache behavior is
  unchanged. Source repair, injected read failure and unrelated-error independence
  are covered without changing permissions or broadly rejecting other providers.
- Archive/delete/quit add no recent closes. Successful archive/delete also remove
  earlier matching references; failed Trash retains them. Project archive excludes
  its chats. The closed-tab list lasts only for this app lifetime.
- `ClosedTabReopenTests` contains generated process/model cases for these paths,
