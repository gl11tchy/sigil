# REA-1247: title allocation in multi-project lists

The resting Recents row previously gave the combined project/time label priority
and up to 120 points. Generated native fixtures reproduced the squeeze before
changing that layout. At 272 points, the representative “Fix flaky test retries
in concurrent requests” title had 94 points; at 200 points it had 23.5 points.
With a working mark, the CJK fixture had only 6 points at the minimum width.
These are measured allocations for fixed strings/fonts, not universal character
count guarantees.

The non-search multi-project row now gives the title priority 1, caps the project
at 24–72 points with trailing alignment and tail truncation, and gives the
separate fixed-size time priority 2. Short project text sits against the
separator rather than leaving a gap. The metadata and mark slots retain their
layout while hover actions overlay them, preserving the title rectangle. Search
and single-project rows retain their original metadata/highlight path. Rename
still replaces the title and removes the accessories. Palette, type, relative
formatting, state decisions, row identity and hover coordinator are unchanged.
