branch does not change that decision or its four exact CI pointer-test exceptions.

## Change and boundaries

Newer compatible CLI versions share one default-collapsed Compatibility control
below the history scroll. Its 26-point row plus eight points of bottom spacing
costs 34 points regardless of provider count. Navigation and the top of the list
stay fixed; the rows take priority over repeated version paragraphs. Zero notices
have no control. The native popover contains each provider name, installed and
checked versions, and the unchanged best-effort consequence. Cmd-Shift-I opens
it; Done and Escape dismiss it and return focus to the control.

Structured `ProviderVersionNotice` facts separate this presentation from the
existing classification rule. The legacy notice text, checked versions, reader,
lifecycle, identity and availability contracts remain unchanged. Unsupported
Codex/Claude majors stay visible in the history list with a Settings action.
Incomplete/unsupported files retain their separate warning and a real Settings
link. Actual read failure keeps the existing error message and Retry.
